Bearer Token Authentication

All SmartShell REST and WebSocket endpoints require a 256-bit hexadecimal Bearer token generated on startup.

Automated One-Click Launch

You can bookmark or launch the interface with the token in the URL query parameter: 

http://127.0.0.1:8080/?token=<YOUR_TOKEN>

Token is located at ~/.smartshell/session.token on the server machine.
